# Ujin S Thomas Portfolio

A modern, responsive personal portfolio website built with React and Vite. Showcasing projects, education, and contact information in a clean, card-based layout.

## 🚀 Features
- Dark theme with blue accent colors
- Fixed top navigation bar with smooth scrolling
- Responsive, full-page layout
- Modern About, Projects, and Education sections
- Vertical education timeline with custom styling
- Stylish contact section with icon links

## 🛠️ Tech Stack
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- CSS (custom, no frameworks)

## 📦 Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/UjinSThomas/portfolio.git
   cd portfolio/portfolio
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Start the development server:**
   ```sh
   npm run dev
   ```
4. **Open in your browser:**
   Visit [http://localhost:5173](http://localhost:5173) (or the port shown in your terminal).

## ✨ Customization
- Update your information, projects, and education in `src/App.jsx`.
- Replace the profile image in `src/assets/port.png`.
- Tweak styles in `src/App.css` for further personalization.
